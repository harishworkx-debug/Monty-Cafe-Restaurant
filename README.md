## 15. Image Rules – Extremely Important

Do not create any JSON-based image system.

STRICTLY DO NOT CREATE:

- images.json
- image.json
- gallery.json
- Image mapping objects
- JSON image arrays
- Base64 images
- Random image fetching systems
- Automatic Unsplash or Pexels image loading

I WILL PROVIDE THE ACTUAL CAFE AND FOOD PHOTOS.

Use images only from the project's `src/assets/` directory.

Import every image directly using normal ES module imports, for example:

```jsx
import cafeHero from "../assets/cafe-hero.webp";
import breakfastImage from "../assets/breakfast.webp";
import coffeeImage from "../assets/coffee.webp";
```

Use these imported variables directly inside JSX.

Before using an image, inspect the actual files and filenames available in `src/assets/`. Never assume an image filename exists.

If images are not yet supplied, create elegant image-free placeholders using CSS gradients and background styling. Do not insert random or unrelated photographs.
